Help & conventions

The explorer is a static, browser-based reader for BMOPF case and result JSON. Start with a built-in example or drop in your own files, then select an asset to connect the views and inspector.

Quick start
  1. Choose a built-in example, open a case JSON, or drop a case into the drop zone. Single-wire opens first as the default overview.
  2. Use the Inventory or Class overview to select a bus or asset.
  3. Switch views to compare geographic placement, a compact single-wire overview, and electrical model sheets.
  4. Attach a result JSON after loading a case to colour assets and inspect solution metrics.
Views

Geospatial uses supplied bus coordinates and line geometry. Buses without coordinates stay explicitly unplaced; synthetic built-in coordinates are labelled as illustrative.

Single-wire collapses phase conductors into an engineering-style overview. Buses are compact dots by default; Display options can show conventional heavy busbars. Paired coils are transformers, and open blades/dashed paths identify open switches.

Electrical detail opens model sheets: terminal connections, coupled matrices, winding and load-element graphs, controls, limits, results, and unresolved fields together. Pin sheets into an atlas, capture a baseline or compare model JSON, and export standalone HTML. The old multi-wire deep links still open this view.

Diagnostics collects validation, bounds, residual, and solution-profile findings from the active result slice.

Visual conventions
  • Electrical sheets use solid connections, labelled terminal rings, and junction dots. Ground symbols attach to the local bus terminal. Selection links conductors, load elements and matrix entries; colour does not assign a phase role.
  • Asset labels separate the semantic class from the identifier: the class is muted italic small-caps, while the identifier is darker and monospaced for quick scanning.
  • An open switch uses an open blade and a dashed connection. Out-of-service assets are faded.
  • Result overlays use five labelled magnitude bins. Display ranges are not acceptance limits; missing results are not zero. Supplied-limit assessments report check outcomes separately.
  • A faint dashed leader in Single-wire connects a manually moved symbol to its computed electrical anchor.
Class overview support

The support column counts how much of each asset class the renderers cover: full means it appears in both the overview and focused views; focused means it is rendered when selected in a detail view; partial means only some semantics are rendered; and raw-only means the record is preserved in the inspector without a diagram renderer.

Data and units
  • Terminal maps are ordered: a pair such as 2→3 means source terminal 2 is connected to destination terminal 3.
  • Branch series entries are R+jX in absolute Ω. Linecode values in Ω/m are multiplied by the branch length.
  • Both branch shunt sections remain visible. Missing entries, supplied zeros, and invalid data are distinct; no physical grounding branch or equal shunt split is inferred.
  • Missing or unsupported semantics remain inspectable as raw properties and are called out rather than silently inferred.
Interaction and accessibility
  • Select assets in any view, follow Related links in the inspector, and use Back/Forward to retrace exploration.
  • In Single-wire, drag buses or device symbols. Bus positions and symbol overrides are stored locally for the active case/layout profile.
  • Use zoom, pan, Focus selection, and Fit / reset for the active SVG. Single-wire offers the topology-aware deterministic layout (tidy tree for radial feeders, layered ranks for meshed networks), an explicit stress layout, and the optional ELK layout, plus page-session Display options for hiding labels/arrows or showing selected labels only. Resize the details panel or table columns with pointer dragging; focused separators also respond to Arrow keys.
  • Use the copy icon beside inspector rows, raw JSON sections, diagnostics, or branch matrices to copy a readable value or record to the clipboard.
  • Keyboard users can Tab to assets, press Enter or Space to select, and use the Inventory search arrows plus Enter to jump to a ranked match.
Large cases and performance

Cases over the overview guidance (more than 500 buses or roughly 5,000 estimated SVG elements) prompt before full rendering. Focused views, Diagnostics, and the deterministic layout fallbacks remain available. The stress layout is self-contained; ELK is optional and may be slower or unavailable on very large graphs.

Provenance and limitations

This tool reads JSON without changing the source files. Matching case/result identities are verified when fingerprints are available; otherwise pairing is labelled unverified. Built-in cases are illustrative CC BY 4.0 fixtures, while reused cases retain their source licences.
